איך להנחות את ה-AI בדיוק באיזו תיקייה לעבוד

💡 טיפ זהב להנחיית AI: כשאתה מבקש מה-AI לבצע שינוי, תגיד לו במפורש את שם התיקייה בלחיצה על "העתק הנחיה ל-AI" למטה. ככה הוא לא יתבלבל ויגיע מיד לקובץ הנכון!
src/app/[tenantId]/admin/ UI מסכים
אחראי על: דשבורד מנהל הארגון, טבלאות קריאות, שיוך נהגים, סינון וניהול קריאות.
  • למשל: שינוי עיצוב הטבלה, הוספת כפתור בממשק המנהל, הוספת מסנן.
הנחיה מוכנה ל-AI:
תעבוד בתיקייה src/app/[tenantId]/admin/ ותעדכן את ממשק המנהל...
src/app/[tenantId]/driver/ UI מסכים
אחראי על: מסך הנהג/טכנאי בשטח, איסוף קריאות, עדכון סטטוס נסיעה ומפת ניווט.
  • למשל: כפתור "געתי ללקוח", תצוגת פרטי קריאה לנהג בטלפון.
הנחיה מוכנה ל-AI:
תעבוד בתיקייה src/app/[tenantId]/driver/ ותעדכן את מסך הנהג...
src/app/[tenantId]/form/ UI מסכים
אחראי על: טופס פתיחת קריאה חדשה על ידי הלקוח/מוסך.
  • למשל: הוספת שדה לטופס, שינוי עיצוב טופס פתיחת קריאה.
הנחיה מוכנה ל-AI:
תעבוד בתיקייה src/app/[tenantId]/form/ ותעדכן את טופס פתיחת הקריאה...
src/app/supadmin/ UI מסכים
אחראי על: מסך מנהל-על (Super Admin) שמנהל את כל הארגונים/הלקוחות במערכת.
  • למשל: הוספת ארגון חדש, ניהול מנויים ודיירים (Tenants).
הנחיה מוכנה ל-AI:
תעבוד בתיקייה src/app/supadmin/ ותעדכן את מסך מנהל העל...
src/app/api/ API שרת
אחראי על: לוגיקה של השרת, שליפת נתונים, שמירת קריאות, התחברות (Login), וייצוא לקבצים.
  • למשל: שינוי לוגיקת שמירת קריאה, הוספת נקודת קצה חדשה (Endpoint), ייצוא אקסל.
הנחיה מוכנה ל-AI:
תעבוד בתיקייה src/app/api/ ותעדכן את לוגיקת השרת/ה-API...
src/lib/ בסיס נתונים
אחראי על: חיבור לבסיס הנתונים (MongoDB / db.ts), אבטחה (auth, csrf, rate limit).
  • למשל: עדכון שאילתת בסיס נתונים, שינוי אופן אימות הסיסמאות.
הנחיה מוכנה ל-AI:
תעבוד בתיקייה src/lib/ ותעדכן את פונקציות העזר או החיבור ל-DB...
public/ קבצים סטטיים
אחראי על: תמונות, הלוגו של המערכת, קבצי אייקונים (Favicon) וקבצי מדיה.
  • למשל: החלפת לוגו, הוספת תמונה חדשה למערכת.
הנחיה מוכנה ל-AI:
תחליף או תוסיף קובץ תמונה בתיקייה public/...
שורש הפרויקט (Root) הגדרות פרויקט
אחראי על: התקנת ספריות חדשות (package.json), משתני סביבה (.env.local), עיצוב גלובלי.
  • למשל: התקנת חבילת npm חדשה, הוספת מפתח API ל-env.local.
הנחיה מוכנה ל-AI:
תעדכן את הגדרות הפרויקט ב-package.json או ב-.env.local...
